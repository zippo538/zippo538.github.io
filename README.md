# Portfolio Mahindra Irvan Saputra

Website portofolio statis yang dibangun dengan HTML, Tailwind CSS, dan JavaScript. Seluruh proyek utama diselaraskan dengan CV.

## Menjalankan lokal

Buka `index.html` langsung di browser atau jalankan server lokal:

```bash
python3 -m http.server 8000
```

Kemudian buka `http://localhost:8000`.

## Deployment GitHub Pages

Repository ini menggunakan struktur root tanpa proses build. Pada **Settings > Pages**, pilih **Deploy from a branch**, lalu pilih branch `main` dan folder `/ (root)`.
